# Соответствие словесного описания и модели

| Описание | Модель | Принятое толкование |
|---|---|---|
| Клиент 0, клиент 1 | `Client0`, `Client1` | Ровно два клиента; каждый повторяет цикл без завершения. |
| Сервер | `Server` | Выбирает один доступный запрос, отвечает именно этому клиенту и ждёт его освобождения. |
| Клиент пытается послать запрос | `waiting0/1 = true` | Флаг ставится **до** синхронной передачи запроса; в это время запрос ещё может быть не принят. |
| Клиент послал запрос, сервер его принял | `request!i` вместе с `request?i` | Один атомарный шаг rendezvous. |
| Запрос принят, разрешение ещё не получено | `accepted0/1 = true` | Наблюдаемый маркер ставится следующим шагом клиента после передачи запроса. |
| Сервер выдал разрешение | `grant0/1!1` вместе с `grant0/1?1` | Один атомарный шаг rendezvous. |
| Клиент работает | `working0/1 = true` | Флаг становится ложным, когда работа закончена. |
| Клиент сообщил об освобождении | `release!i` вместе с `release?i` | Сервер получает соответствующее освобождение и только затем снова принимает запрос. |

Все каналы имеют вместимость 0. Между `working_i = false` и `release!i` сервер ещё занят этим клиентом. Внешние сбои, потери и задержки отсутствуют по явно помеченному учебному допущению. Эти соответствия требуют подтверждения, если вывод нужно перенести на конкретную реализацию.
