# Счётчик не «никогда не превышает 3» — он достигает 4

## Ответ (кратко)

**Нет, свойство «счётчик никогда не превышает 3» не выполняется.** Счётчик `total`
растёт `0 → 1 → 2 → 3 → 4`, и только после значения **4** условие `total > 3`
становится истинным и цикл разрывается (`break`). Таким образом, счётчик **превышает
3** — он доходит до 4.

## Как проверяли

Движок `mcd` (явный поиск, SPIN-совместимый набор Promela) **отклоняет исходную
модель как есть**: конструкция `unless` не входит в поддерживаемый подмножество
Promela, и в стандартном SPIN/Promela `unless` вообще не является оператором
(исполняется только в препроцессорных `#`-директивах). Поэтому для исходного текста
статус — `not-executed`.

Чтобы получить вердикт по задуманной семантике, модель была переписана в
поддерживаемый подмножество, сохраняя тот же смысл «инкремент, пока `total > 3`
ложно, иначе `break`» (файл `model_checkable.pml`):

```promela
int total;

active proctype worker()
{
  do
  :: total <= 3 -> total = total + 1
  :: total > 3  -> break
  od
}
```

### Проверки (модель `model_checkable.pml`)

| Свойство | Формула | Статус | Доказательность |
|---|---|---|---|
| Счётчик никогда не превышает 3 | `[](total <= 3)` | **violated** | exhaustive (полный поиск, цикл завершён) |
| Счётчик достигает 4 | `<>(total == 4)` | **verified** | exhaustive |

Контрпример (полный поиск, без fairness), декодированный из трека:

```
total = 0
  -> total = 1
  -> total = 2
  -> total = 3
  -> total = 4     # тут total > 3, и цикл выходит через break
конец: total = 4
```

Состояние пространства — 11 состояний, 10 переходов; поиск завершён полностью,
fairness не требуется (свойство safety-типа).

## Оговорка (важная)

Вердикт получен по **верной переписке** исходной модели в поддерживаемый подмножество,
а не по буквальной обработке исходного текста (там `unless`). Если под `unless { … }`
имелась другая семантика — например, что инкремент идёт *пока* `total > 3` ложно в
каком-то другом смысле, — уточните, и я перепроверю. При задуманной же семантике
ответ однозначен: **счётчик доходит до 4 и превыщает 3.**
