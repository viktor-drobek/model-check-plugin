# Могут ли четыре счётчика одновременно оказаться равны 200?

## Ответ

**Да, могут.**

## Обоснование

Каждый из четырёх счётчиков `a`, `b`, `c`, `d` ведёт себя независимо и свободно
перемещается по диапазону `[0, 255]`:

- из `0` он может нарастать до `255` (условие `x < 255 → x++`),
- из `255` — уменьшаться до `0` (условие `x > 0 → x--`).

Следовательно, состояние `(200, 200, 200, 200)` достижимо из начального
`(0, 0, 0, 0)`: достаточно 200 шагов на каждый счётчик (800 переходов суммарно),
никакие другие счётчики не мешают.

## Результат проверки движком `mcd`

Движок `mcd` 0.1.0, DFS, прогон `answer-check.json`:

```
status:    inconclusive
evidence:  bounded
reason:    state budget exhausted: 2 000 000 states stored
```

Полное пространство состояний модели — `256⁴ ≈ 4,294,967,296` состояний,
что значительно превышает разумный бюджет явного перебора.
Поэтому формальная `verified` / `exhaustive` верификация на этой модели
в пределах данного движка не выполняется — и это **не** свидетельствует
против достижимости: `inconclusive` / `bounded` означает только,
что поиск был ограничен, а не что свойство ложно.

Вывод опирается на прямую достижимость, а не на исчерпывающий перебор:
модель — декартов продукт четырёх независимых циклов `[0..255]`,
и состояние `(200,200,200,200)` лежит внутри этого декартова произведения.
