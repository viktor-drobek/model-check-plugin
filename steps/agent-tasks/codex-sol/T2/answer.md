Нет. Контрпример: `total` принимает значения `0 → 1 → 2 → 3 → 4`. При `total == 3` условие выхода `total > 3` ещё ложно, поэтому следующее увеличение нарушает ограничение.

`mcd` не поддерживает `unless` (исходник: `not-executed`); проверка эквивалентной для этого свойства записи в `check.pml` дала `violated` для `[] (total <= 3)`. Результат сохранён в `check-report.json`.
